A LITTLE GUIDE

探索开源，只需一步。

  1. 点击「一键分析」，同时准备累计热度与增星数据，dsh 会读取 GitHub Star 总数前 100 仓库，并根据描述、Topics 和 README 分析。
  2. 按兴趣分类或标签筛选；点开卡片查看真实 Star、Fork、Release 下载量与最近提交。
  3. 「下载 ZIP」保存源码压缩包，「克隆项目」保存 Git 工作目录；两者都在 downloads 目录中，以实际文件标注已下载。
  4. 「检查更新」扫描默认目录，也会分析榜单外的 Git 项目。GitHub 项目可下载最新 ZIP 或快进拉取；非 GitHub 本地项目仅分析。

手机与本机连接同一个局域网，打开上方 URL，即可访问和操作。周／月增星排序范围是累计 Star 前 100，统计完整过去 7／30 天新增 Star，并非净增长。初次分析需要网络连接和已配置模型的 dsh。已有分析会自动从本地缓存恢复，顶部标注上次分析时间。可在「GitHub 访问配置」中申请并保存 Token 到 config/github.token，该文件优先于 GITHUB_TOKEN。灵感可通过「换一换」生成新的构想，并保存生成时间。下载量仅包含公开 Release 附件，GitHub 不提供源码总下载量。Token 按 dsh 实際返回的用量汇总；费用单位 USD，参考 DeepSeek 官方模型价格估算（2026-10-13 核验），未知模型可配置单价，缺少报价时不会当作免费。
